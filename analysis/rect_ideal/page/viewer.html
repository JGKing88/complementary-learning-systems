Rectified ideal codes

Single-unit maps, Hopfield measures and place-field statistics for every sparsity and unit count, on the 1716 × 1716 scaffold
Population
Code
The ideal code with half as many waves as units, rotated by a fixed Walsh-Hadamard matrix: relu(Q z − t), scaled to unit length at each place.
Threshold
t is set by the slider, so that share of units is active at every place.
Kernel r
Rectifying narrows the population kernel, more so when sparser. "Matched" redraws the code at the r that keeps the kernel as wide as the unrectified ideal's, which recomputes the maps at each slider step. "Fixed" keeps one code's r and only moves the threshold, which is instant.
Modules
The code depends on them only through the scaffold size: 1716 cells for 11, 12, 13 and 3795 for 11, 15, 23. "r scaled" widens the kernel by the larger modules' period (15.6 against 12.0 cells). On the larger scaffold the map above shows its first 1716 cells.
Speed
4096 units take a few seconds per arena; use a smaller arena to drag smoothly.
Model
Vector-HaSH's place layer, relu(Wpg g − θ): 400 cells, Wpg Gaussian with about half the entries pruned (seed 0), drawn as build_scaffold draws it.
Input
Hippocampus reads the one-hot grid code, as the model does. Smoothed input reads the smoothed grid code the encoder reads.
Threshold
One θ for the whole layer, set by the slider so that share of cells is active on average over the whole scaffold (exact). Cells differ in how much they fire.
Modules
Each module set has its own Wpg: 434 grid inputs for 11, 12, 13 and 875 for 11, 15, 23.

Waves with |n| below the cutoff are dropped and replaced by faster draws from the same Gaussian, so there are always 512. |n| counts cycles across the 1716-cell scaffold, so a cutoff c removes every wavelength longer than 1716 / c cells. These are the probe's draws (ideal encoder option nmin). The check against Python uses the full draw.

Threshold

This population has no threshold of its own. Checked: it shows relu(y − θ), with θ set so the slider's share of its units is active (from its outputs at 2048 sample places). Unchecked: it shows its own output and the slider does not affect it. The setting applies to every population of this kind.

The grid results below exist only at 2, 5, 10, 20, 35 and 50%; they show the one nearest the slider.

Grey squares are the 118 patches of 50 × 50 cells both trained encoders (tanh and ReLU k128, seed 43) were trained on, 10% of the scaffold.

Field detection
0%

These set the field outlines, field counts and field sizes, and never change the map. A field is a 4-connected region at or above the threshold fraction of the unit's peak in this arena, with at least the minimum size. At 0% a field is any connected region where the unit is above zero, the definition the grid results use (they also report 20% of peak).
