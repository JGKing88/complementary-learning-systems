The Attractor Threshold

The recall dynamics in this stack have two regimes with a sharp boundary between them. Which side you are on is set by a single number — and production sits four orders of magnitude on the wrong one.

This page collects what is derived about the Hopfield layer, separately from what was measured. The measurements live in docs/EXPERIMENTS_HOPFIELD_PROBE.md; everything here follows from the update rule, and the numbers appear only to check the algebra.

01The system

Patterns are stored Hebbian at unit norm, with the diagonal zeroed, and recall iterates a normalised tanh map:

W = s · (ZᵀZ − diag) s = scale, default 1/D
x ← normalize( (1−α)·x + α·tanh(β · W x) ) D = 1024 (embedding dim), K = number of stored patterns, Z = (K, D) unit rows. Production: s = 1/D, α = 1, β = the encoder's gain, one step.

Two things about this are load-bearing and easy to miss. The normalize makes any scalar multiplying the whole update irrelevant, so β and s are the same knob — the map is exactly invariant under (p → λp, β → β/λ²). And storing at unit norm pins the pattern energy at S = 1, so that half of the loop gain cannot compensate for anything.

02The regime parameter

For unit-norm patterns with modest overlap, a cue with support in the memory subspace gives ‖Wx‖ ≈ s. Spread over D coordinates, the argument the tanh actually receives is

u = β · s / √D The per-coordinate tanh argument. Not β·s, which is the norm ratio — the distinction is a factor of √D and it is the one this project got wrong for a while.

The tanh bends at an argument of order one, so the boundary is u ≈ 1, that is β·s ≈ √D. At the default s = 1/D this means:

βthreshold = D3/2 = 32 768 Production runs β = 3.7 (v35) or 100 (L7). Three orders short.

03The linear limit

When u ≪ 1, tanh(v) ≈ v and the scalars cancel in the normalisation, so at α = 1 the map collapses to

x ← normalize(W x) Power iteration on a symmetric matrix.

The fixed points of power iteration are exactly the eigenvectors of W, and only the one with the largest eigenvalue is stable. A stored pattern is an eigenvector only if the patterns are mutually orthogonal; with any overlap it is not, so stored patterns are saddles.

Consequence

There is exactly one attractor, and it is not a memory. Every cue converges to the same leading eigenvector, at a rate set by the eigenvalue gap. Recall therefore does all of its useful work in the first application — it is a matched filter — and every subsequent step moves the state away from the memory and toward the blend most shared across the stored set.

This is why the q readout decays monotonically with recall depth in production, and why steps = 1 is not merely optimal but the only setting that retrieves anything.

04The saturated limit

When u ≫ 1 the tanh clips every coordinate and the map becomes, after normalisation,

x ← sign(W x) / √D The image is a hypercube corner, whatever the input was.

So a stored pattern z₁ is a fixed point if and only if two independent things hold:

(a) The pattern is itself a corner

The map's image is always sign(·)/√D, so z₁ can only be fixed if z₁ = sign(z₁)/√D — every coordinate at the same magnitude. This is a property of the encoder, not of the dynamics, and no setting of β, s or α can produce it. It is measured as the cosine between a pattern and its own binarisation.

(b) One application preserves every sign

Writing the update for a corner pattern, with c_k = ⟨z_k, z₁⟩ and the zeroed diagonal contributing K/D:

W z₁ = s · [ (1 − K/D)·z₁ + Σk≠1 c_k z_k ] Self term versus cross term, coordinate by coordinate.

A coordinate flips when the cross term beats the self term there. The cross term is a sum of K−1 signed contributions of size |c_k|/√D, so it behaves as a random walk of standard deviation ≈ √(K)·c̄/√D against a self term of (1−K/D)/√D. Requiring no coordinate to flip is a union bound over D of them, which costs a factor √(2 ln D) in the margin and yields

Kmax ≈ D / (2 ln D) = 74 at D = 1024 For near-orthogonal corners. Correlated patterns cost capacity beyond this.
Check — a number the derivation was not fitted to

An independent sweep (EXPERIMENTS_NAV_P2.md §5.7) measured the capacity of this network at D = 1024 to lie between 50 and 100. The union bound predicts 74.

05Verification

Two closed-form predictions follow. In the linear regime the recall term's norm relative to a unit cue is β·s; in the saturated regime every coordinate is ±1 so the norm is capped at √D = 32 regardless of β. Both hold to three significant figures.

The saturated row is the sharper test: 31.96 against a ceiling of exactly √1024, which the linear formula would have put at 976.

06What each knob actually does

The derivation assigns the knobs to jobs, and a separate three-decade sweep of β confirmed the assignment empirically — a 1000× change in β left angular error and retrieval untouched and moved only step-invariance.

knobsetscannot set
encoder gaincorner-ness (a) → retrieval, angular error the loop gain
β, storage scalethe loop gain → step-invariance corner-ness; they are one knob, not two
αintegration rate, once the recall term rivals the cue anything at all while u ≪ 1
K—bounded by (b) at ≈ D / (2 ln D)
Why α is not a free knob

The retained-cue term has norm (1−α) and the recall term has norm β·s — which is 0.0036 for v35 and 0.098 for L7. Any damping larger than that swamps the memory with the cue, so at production's loop gain α is not an integration rate; it is a cue-retention rate. Saturated, the recall term is 32× the cue and α becomes meaningful. α and the loop gain cannot be moved independently.

07What the analysis does not cover

  1. The continuous cell bank. Retrieval here is scored against the embeddings of all cells, which are not corners. A saturated recall returns a corner, and a corner is far from every continuous cell embedding — so retrieval can collapse while the dynamics behave exactly as derived. This is the widest gap between “is an attractor network” and “is a useful position readout,” and it is what made raising β alone a net loss.
  2. The intermediate regime, u ≈ 1. Partial saturation has neither limit's simplification. Everything above is asymptotic on one side or the other.
  3. The angular cost of raising encoder gain. Pushing gain toward the corner condition distorts the smooth chart the tangent projection reads, and how much is a property of the encoder's learned geometry — outside this analysis entirely.
  4. The correlation penalty on (b). The union bound assumes near-orthogonal corners. Real overlap is measured (worst-pair cosine 0.52 for L7-s42, and an alias tail reaching 0.88) but its effect on Kmax is not derived.
The correction that produced this page

The rescue sweep reported β·s·√D under the name “tanh argument”. It is D times the actual argument u = β·s/√D, so the band it identified as optimal — 1 to 10 — is u ≈ 10⁻³ to 10⁻², firmly linear rather than the partial saturation the name implied. Every ranking in that sweep stands, because the coordinate is monotonic in β·s. Only the regime label was wrong, and it was wrong for long enough to shape several conclusions.
