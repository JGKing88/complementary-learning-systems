Ideal encoder · field width against kernel width · 2026-11-23

A wide kernel implies wide fields

The memory needs a population kernel about 38 cells wide. The kernel is the average overlap of each cell's map with a shifted copy of itself, so each cell has to fire across a region about that wide. A fast input can break that region into small patches, but it is the same region, it costs units, and it predicts a clustering of fields that recordings do not show. The clean prediction is wide fields in the population the memory reads.

The two quantities

Field widthA property of one unit: how long a stretch of positions it fires over. Mouse dorsal CA1 fields are 0.4 to 0.5 grid periods. The current sparse ideal code has 2.5.
Kernel widthA property of the population: how far apart two positions can be and still have similar activity vectors. The memory needs this to be wide, because the similarity to a stored goal is the only signal that says which way the goal is.

The unit is a thresholded Gaussian random function

1. Definition

Positions x are cells of the 1716 × 1716 scaffold. The ideal code has M = 512 waves with integer frequency vectors ni, and ωi = 2πni/1716. Each component of ωi is drawn from N(0, 1/r²) and rounded to the lattice. Write θi(x) = ωi · x. The code has 2M units:

zi(x) = cos θi(x) / √M,    zM+i(x) = sin θi(x) / √M

Unit u of the rotated code applies row u of an orthogonal matrix Q, scales by √(2M), and thresholds:

yu(x) = √(2M) Σj=1..2M Quj zj(x),    su(x) = max(yu(x) − t, 0)

2. Each wave enters as one cosine with an amplitude and a phase

Substitute the code into the sum and pair the cos and sin of each wave. Write c = Qu,i and s = Qu,M+i:

yu = √(2M) Σi (c cos θi + s sin θi) / √M = √2 Σi (c cos θi + s sin θi)

Let A = √(c² + s²) and choose φ with cos φ = c/A and sin φ = s/A. Then, by the angle-difference identity,

c cos θ + s sin θ = A (cos φ cos θ + sin φ sin θ) = A cos(θ − φ)

So, with aui = √2 A:

yu(x) = Σi aui cos(θi(x) − φui),    aui² = 2(Qu,i² + Qu,M+i²)

All units share the 512 frequencies. The rotation gives each unit its own amplitudes and phases.

3. Variance across units, at one position (exact)

Fix a position x and average over the 2M units. Expand the square and use Σu QujQuk = 1 if j = k and 0 otherwise, which is what orthogonal means:

(1/2M) Σu yu(x)² = Σj,k zj(x) zk(x) Σu QujQuk = Σj zj(x)² = (1/M) Σi (cos²θi + sin²θi) = 1

So at every position the inputs across units have mean square exactly 1. This is the variance the threshold acts on.

4. Correlation across units, between two positions (exact)

The same expansion for two positions x and x′ = x + d, then cos α cos β + sin α sin β = cos(β − α):

(1/2M) Σu yu(x) yu(x′) = Σj zj(x) zj(x′) = (1/M) Σi (cos θi cos θi′ + sin θi sin θi′) = (1/M) Σi cos(ωi · d)

Call this ρM(d). It depends on the separation only, not on where the pair sits.

5. Its expectation is a Gaussian

For a fixed d, ω · d = ωxdx + ωydy is a sum of two independent Gaussians, so it is Gaussian with mean 0 and variance (dx² + dy²)/r² = |d|²/r². For any X ~ N(0, v), E cos X is the real part of E eiX = e−v/2. Therefore

ρ(d) = E ρM(d) = E cos(ω · d) = exp(−|d|² / 2r²)

Rounding the frequencies to integers adds 1/12 to a variance of 139 (in units of the integer lattice, at r = 23.2), which changes r by under 0.1%. A finite draw departs from the expectation: far from zero, ρM has standard deviation 1/√(2M), and this draw's kernel is 2% wider than exp(−d²/2r²).

6. One unit over positions (approximate)

Now fix a unit and average over all positions of the scaffold, written ⟨·⟩. Three facts, each because a cosine with a nonzero integer frequency sums to zero over a whole number of periods:

⟨cos(θi − φ)⟩ = 0   if ni ≠ 0
cos α cos β = ½ cos(α − β) + ½ cos(α + β)
⟨cos(θi − φi) cos(θj − φj)⟩ = ½ if i = j,   0 if ni ≠ ±nj

For i = j the difference term is cos 0 = 1 and the sum term has frequency 2ni and averages to zero. For different frequencies both terms have nonzero frequency. If every frequency were distinct up to sign and nonzero, the cross terms would vanish and

⟨yu²⟩ = Σi aui²/2 = Σi (Qu,i² + Qu,M+i²) = Σj Quj² = 1
⟨yu(x) yu(x + d)⟩ = Σi (aui²/2) cos(ωi · d)

The second line uses the same product identity with β = α + ωi · d. It is a weighted average of cos(ωi · d) with weights that sum to 1, so its expectation is the same Gaussian.

The condition does not hold exactly. In this draw only 395 of the 512 frequencies are distinct up to sign, and one is the zero vector, because integer vectors with a standard deviation of 11.8 collide. Waves that share a frequency add their amplitudes before squaring. Computed exactly, the per-unit variance over the scaffold is 1.002 on average with standard deviation 0.034 (range 0.90 to 1.11). So a single unit's variance is 1 to within a few percent, not exactly. Steps 3 and 4 are unaffected, because they never use distinct frequencies.

7. Why the values are Gaussian

Pick a position at random. By step 2, yu is a sum of 512 cosine terms. By step 6 the terms with different frequencies are uncorrelated, and no term carries much of the variance: the largest wave's share aui²/2 is 1.3% for a typical unit and 2.6% at most. A sum of many small, nearly independent terms is close to Gaussian by the central limit theorem. Applied to the pair (yu(x), yu(x + d)) the same argument gives a joint Gaussian, which is the meaning of "Gaussian random function". Uncorrelated is weaker than independent, and I have not proved the independence the theorem needs, so this step rests on the check below (40,000 random positions, all 1,024 units).

8. This is the model of Mainali, Azeredo da Silveira and Burak (2025)

They model each CA1 cell as a thresholded, rectified sample of a Gaussian process, simulate it with a Gaussian correlation function, and justify the Gaussian by the same central limit argument for random projections. Their two parameters map onto ours: their correlation length σ = √(−ρ(0)/ρ″(0)) is our r (step 14 below), and their normalised threshold θ is our t. Our 10% active is θ = 1.28; they infer θ = 1.1 for bats in a 200 m tunnel. So the rotated and sparse ideal codes inherit their fit to field sizes, counts and shapes. Three things differ:

  • Their cells are independent samples. Ours share 512 frequencies through one rotation, which is what makes steps 3 and 4 exact with only 1,024 units. I found no population-similarity analysis in their paper; the kernel follows from their model by step 11.
  • They fit σ and θ separately for each dataset, and σ grows with the size of the environment. In our code r is one fixed number.
  • They add a spread of thresholds across cells to explain why a cell's field count is correlated between the two flight directions. Our units all share one threshold, which is probably why the coding comparison found no code with Rich's overdispersed field counts.

Why a wide kernel implies wide fields

9. Setup

Take two positions d apart. Across units, the inputs (Y, Y′) have unit variance (step 3) and correlation ρ = ρM(d) (step 4), and are close to jointly Gaussian (step 7, with the rows of Q playing the role of the random draw). The rates are S = (Y − t)+ and S′ = (Y′ − t)+. Write φ for the standard normal density and Φ for its cumulative. The share of units active is p = P(Y > t) = 1 − Φ(t).

10. Mean and mean square of the rate

Two integrals are needed: ∫t∞ y φ(y) dy = φ(t), because φ′ = −yφ; and ∫t∞ y² φ(y) dy = tφ(t) + 1 − Φ(t), by parts. Then

m1 = E S = ∫t∞ (y − t) φ dy = φ(t) − t (1 − Φ(t))
m2 = E S² = ∫t∞ (y² − 2ty + t²) φ dy = (1 + t²)(1 − Φ(t)) − tφ(t)

11. The cross moment and the kernel

Expand the rate function f(y) = (y − t)+ in Hermite polynomials Hek, which satisfy E[Hej(Y) Hek(Y)] = k! if j = k and 0 otherwise:

f(y) = Σk≥0 ck Hek(y) / k!,    ck = E[f(Y) Hek(Y)]

For a Gaussian pair with correlation ρ, Mehler's formula says E[Hej(Y) Hek(Y′)] = k! ρk if j = k and 0 otherwise. Multiply the two expansions and take the expectation term by term:

C(ρ) = E[S S′] = Σk≥0 ck² ρk / k!

The coefficients: c0 = E f = m1. c1 = E[f(Y) Y] = ∫t∞ (y² − ty) φ dy = 1 − Φ(t). For k ≥ 2, integrating by parts twice, with Hekφ = −(Hek−1φ)′, gives E[f Hek] = E[f″ Hek−2], and f″ is a unit spike at t, so ck = φ(t) Hek−2(t).

The Pearson correlation of the two population vectors subtracts the mean rate m1 and divides by the variance m2 − m1². The k = 0 term of the series is m1², and at ρ = 1 the series is m2, so

K(d) = Ft(ρ(d)),    Ft(ρ) = (C(ρ) − m1²) / (m2 − m1²) = Σk≥1 ck² ρk/k!  /  Σk≥1 ck²/k!

Every coefficient is a square, so Ft rises from 0 at ρ = 0 to 1 at ρ = 1 and is increasing and convex in between. The kernel depends on separation only through ρ(d).

12. Kernel width

Let ρ* be the solution of Ft(ρ*) = ½, found numerically; it depends only on t. The kernel is at half height where ρ(d) = ρ*:

exp(−d²/2r²) = ρ*  ⇒  d² = 2r² ln(1/ρ*)  ⇒  FW = 2d = 2r √(2 ln(1/ρ*))

Measured against predicted FW is 34.2 / 34.2, 38.4 / 38.5 and 29.6 / 29.6 cells on three codes.

13. Field width from Rice's formula

Now follow one unit along a straight track, and treat y as a stationary Gaussian function with unit variance and correlation ρ(d) (steps 6 and 7). Differentiate the covariance: Cov(y(x), y′(x + d)) = ρ′(d) and Cov(y′(x), y′(x + d)) = −ρ″(d). At d = 0, ρ′(0) = 0 because ρ is even, so the value and the slope at one point are independent, and the slope has variance

λ2 = Var y′ = −ρ″(0)

The input crosses a level u upward within a short step dx when the slope is some v > 0 and the value lies in the interval of length v dx just below u. Integrating over slopes, with the value and slope independent:

ν(u) = ∫0∞ v p(y = u, y′ = v) dv = φ(u) E[max(y′, 0)] = (e−u²/2/√(2π)) (√λ2/√(2π)) = (√λ2 / 2π) e−u²/2

The middle step uses E[max(V, 0)] = s/√(2π) for V ~ N(0, s²). This ν is the number of upward crossings per cell of track. Over a long track of length L, the unit is above u for a length L(1 − Φ(u)), and it has Lν(u) fields, since each field starts with one upward crossing. Mean field width is the ratio:

W = (1 − Φ(u)) / ν(u) = (2π / √λ2) (1 − Φ(u)) eu²/2

The field width uses ρ only through its curvature at zero.

14. For a Gaussian ρ both are multiples of r

Differentiate ρ(d) = exp(−d²/2r²) twice:

ρ′ = −(d/r²) ρ,    ρ″ = (d²/r⁴ − 1/r²) ρ,    ρ″(0) = −1/r²  ⇒  λ2 = 1/r²

15. Conclusion

Changing r scales the kernel and the field together. Changing the threshold moves their ratio slowly: from 50% to 2% active it changes by a factor of 1.5 under the 20% rule, and it is still 0.70 at 0.01% active under the threshold cut. So in this family a field is never much narrower than about 0.7 of the kernel. At the kernel the memory uses, 38 cells, that is fields of about 30 cells, or 2.5 grid periods.

The underlying reason does not depend on the family. By step 4, the kernel is the average over units of the product of a unit's activity at two places. A kernel that is still 0.6 at 16 cells means a unit firing here is usually also firing 16 cells away.

The one way around it, and why it is not compelling

Steps 12 and 13 read different parts of ρ. The kernel reads where it falls to ρ*, and the field reads its curvature at zero. A second, faster component in the input changes the curvature without moving the rest. With a slow share 1 − a at scale R and a fast share a at scale rs:

ρ(d) = (1 − a) exp(−d²/2R²) + a exp(−d²/2rs²),   λ2 = (1 − a)/R² + a/rs²

The second formula is step 13 applied to each term, using step 14 for the second derivative of a Gaussian at zero: −ρ″(0) = (1 − a)/R² + a/rs². The fast term is the larger one when a/rs² > (1 − a)/R², that is, a/(1 − a) exceeds (rs/R)², about 2% for R = 23.2 and rs = 3. At a = 0.3 the length 1/√λ2 is 5.4 cells against 23.2, and the measured field width falls from 30 to 8 cells. Beyond a few cells ρ is the slow term scaled by 1 − a. The rate kernel loses more than that, because Ft is convex: at 16 cells it goes from 0.61 to 0.32 at a 30% fast share.

Why this is not a real escape.

  • The firing region is unchanged. Each unit still fires across a region the width of the kernel. Only the filling changes, from solid to patchy.
  • A recording would agree with the picture. With Poisson spikes at a 10 Hz peak, 1 s per cell and one cell of smoothing, a 5% fast share reads as 1.4 fields of 12 cells: one large textured field. At 50% the patches do survive as separate fields (6.8 cells recorded against 6.4 true), but they sit clustered in one region.
  • The clustering is the only signature, and recordings do not show it. By field size and count the 50% code and a single-scale small-field code are the same (6.8 cells and about 2.4 fields per unit each). They differ only in whether a cell's fields are clustered. Rich 2014 reports a cell's fields placed at random on a 48 m track, and Mainali 2025 find the gaps between a cell's fields consistent with a Gaussian process that has one correlation length.
  • It costs units in the direction readout. The readout takes a one-cell difference of the similarity, and a code with small patches changes a lot per cell. With a centred difference the error falls as about 1/√units, so holding it fixed needs units in proportion to about 1/W² (a fit over 92 codes, exponent 1.1 to 1.25 on 1/(W√D)). Production's forward difference adds a bias that units do not remove: 41°, 42° and 42° at 1024, 4096 and 8192 units for a 5% fast share. The bias comes from projecting recalled minus current onto the code's change over one step, where the current code's own projection is minus half the step's length. In symbols, with unit-length codes z and z′ one step apart and b = z′ − z: |b|² = 2 − 2 z · z′, so z · b = z · z′ − 1 = −|b|²/2, and the projection on the unit vector b/|b| is −|b|/2. This is exact on the first axis and nearly so on the second, which is orthogonalised against the first.
  • The fast input cannot be the grid code itself. A sum of inputs from modules with periods 11, 12 and 13 has no wavelength above 13 cells and partly repeats every period. Smoothing leaves each module mostly its first harmonic (77% of its power at the production width), so a random projection correlates 0.84 with itself 12 cells away. As a fast input its ripple gives the readout a slope error that units do not average away: reach 0.55 at a 10% share with 4096 units.

What this predicts

The population the memory reads has fields about as wide as its kernel: 0.7 to 1.1 kernel widths under the 20% rule. A kernel wide enough for navigation over tens of cells means fields a few grid periods wide. Kjelstrup 2008 found fields and population correlations of that scale in intermediate and ventral CA3. Mainali's fitted correlation lengths give a second test, because with their σ and θ the kernel width follows from the formula above without any population recording. I have not done that calculation.

Possible next step: two populations

Give some cells only the fast input, so they have small scattered fields, and the rest only the slow input, so they have wide fields. No single cell then has clustered fields, and the population kernel is still a narrow peak on a wide base. The memory would store all of them and read direction from the wide-field cells alone, which makes the first group dorsal-like and the second ventral-like. This has not been run. The nearest arm I ran used grid-driven cells as the small-field group and the biased forward readout, so it does not test it.
