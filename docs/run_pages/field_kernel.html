Ideal encoder · field width against kernel width · 2026-11-21

Can a code have small place fields and a wide kernel?

Yes. Field width and kernel width are two different moments of one spectrum. Give each unit a slow input and a fast input before the threshold and they separate. Retrieval is unchanged. The direction readout gets noisier and needs more units.

What I found

  1. The kernel is fixed by the input's correlation and the threshold. Predicted and measured widths agree on five different spectra (for example 38.5 against 38.4 cells).
  2. Field width follows the spectrum's second moment. A fast share above about 2% already dominates it, while the kernel's shoulder only falls in proportion to the slow share. With one scale the two are locked, and sparsity alone buys at most 1.5× smaller fields.
  3. Retrieval is unchanged. Exact retrieval stays at 1.000 and the basin at 31 to 36 cells. A single-scale code with the same small fields retrieves 0.54 with a basin of 6.5.
  4. The direction readout degrades in two ways. Production's forward one-cell difference has a bias that grows as fields shrink: 41°, 42° and 42° at 1024, 4096 and 8192 units. A centred difference removes it. What remains is noise that falls as about 1/√units, so units needed grow as about 1/W².
  5. The fast input cannot come straight from the grid code. A linear readout of modules 11, 12 and 13 has no wavelength above 13 cells. Its ripples are a systematic slope error that more units do not remove. A random projection of the smoothed grid code is periodic for the same reason. Smoothing leaves each module its first harmonic, and the projection correlates 0.84 with itself 12 cells away.

Where the mouse target stands

Fields of 0.67 grid periods work at 4096 units. Fields of 0.52 reach 0.875 at 8192 units. By the unit law, matching the baseline's direction error at 0.5 needs roughly 16k to 32k units. That last number is an extrapolation.

In a 20-cell arena the mouse-sized code has 49% of units active and 1.55 fields per active unit, against 22% and 1.00 for the baseline.

Not done

  • 16k to 32k units on the real probe.
  • The RL controller on these codes. It may tolerate a noisier direction signal than the greedy probe walk.
  • Whether to change the production readout to a centred difference. The forward-difference bias is in the agent's readout, so any small-field encoder will have it there.
